# CUBE STUDIO

ブラウザで遊べる3×3ルービックキューブです。ビルドやインストールは不要です。

## 起動

親フォルダーの `index.html` または `dist/index.html` を Chrome、Edge、Firefox、Safari などのブラウザで開いてください。親フォルダーのHTMLは必要なコードとスタイルをすべて含んでいます。編集後は `node build.cjs` で更新できます。

## 操作

- 色のマスをドラッグ：指に追従して列を回転、離すと90度に確定（短いドラッグは元に戻る）
- 中央の列をドラッグ：中段も回転、履歴には M / E / S を表示
- キューブの外の背景をドラッグ、または矢印キー：視点を変更
- U / D / F / B / R / L：上・下・前・背・右・左の面を90度回転
- Shift + 面のキー：反時計回り
- Ctrl / Command + Z：1手戻す
- 「シャッフルして挑戦」：22手で混ぜて新しいチャレンジを開始
- 「キューブをリセット」：完成状態に戻し、手数とタイマーをリセット
- 「正解手順を見る」：現在の状態から完成までの回転順を表示
- 「次の1手を回す」：表示されている手順の最初の回転を実行
- 「初心者向けの解法を学ぶ」：層ごとにそろえる一般的な解法の7段階、目標の図、基本手順を表示
- 「この状態の手順を作る」：キューブの現在の配色から7段階の解法を計算（履歴不要）
- 「解法の次の1手」：計算した手順を90度ずつ実行し、段階に合わせて説明を切り替える

面の名前は視点を変更しても変わりません。タイマーは最初の回転から始まり、完成すると止まります。表示している手数は、戻した操作を除く回転数です。

キューブと次の回転の操作は常に画面内に表示します。PCは左右、スマートフォンは上下の配置で、操作と解法の詳細だけが独立してスクロールします。手順を閉じるには操作欄の右上の「×」を押してください。

正解手順は、シャッフルとその後の操作を逆にたどる確実な手順です。連続する同じ面の回転はまとめて打ち消しますが、最短手順の探索は行いません。ドラッグによる中央列の回転や1手戻す操作にも対応し、回転が確定するたびに更新されます。手順ボタンで実行した回転も、手数とタイマーに含まれます。

一般的な解法は、白のクロス、白の角、中段エッジ、黄色のクロス、黄色のエッジの位置、黄色の角の位置、角の向きの順に進みます。各段階の基本手順を、現在のピースの位置・向きに合わせて組み合わせます。中央列を動かして中心の向きが変わっている場合は、最初に3つの列を順に回して全体の向きを整えます。

提示された次の回転を手動で行った場合も進捗が進み、直前の回転を戻すと進捗も戻ります。異なる回転を行った場合は「この状態の手順を作る」で再計算できます。一般解法の手順は学習用で、最短ではありません。最後の角の向き合わせでは下段が途中で崩れますが、手順を最後まで実行すると復元されます。

## 構成と検証

CSS 3Dと標準JavaScriptのみで動作します。フォントはオンライン時にGoogle Fontsから読み込み、読み込めない場合はシステムフォントを使います。アプリ本体に外部ライブラリや通信は不要です。

`node verify.cjs` で、6面と中央3列の回転・逆回転、標準手順、1,000手の整合性と逆順復元、視点変更後のドラッグ方向、正解手順による復元と次の1手・取り消しの整合性を検証できます。

`node verify-beginner.cjs` で、履歴を渡さずに一般解法を計算し、各段階で既にそろえた層が保たれることと最終完成を検証できます。引数に数を指定すると検証するランダム配置の数を変更できます。

説明と基本手順は [Rubik’s公式ガイド](https://rubiks.com/solve-guide)、[Cube.Academy](https://www.cube.academy/how-to-solve-a-rubiks-cube)、[Ruwix](https://ruwix.com/the-rubiks-cube/how-to-solve-the-rubiks-cube-beginners-method/) を参考にしています。

公開する場合は親フォルダーの `index.html`、または `dist` の5ファイルを静的ホスティングに配置してください。
